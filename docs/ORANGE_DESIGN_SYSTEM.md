# Orange Design System

MyExplorer nutzt Orange als klare Hauptidentität, kombiniert mit Amber, Dunkelgrau und Schwarz. Das Design darf zu orange angepassten Android-, Linux- oder Windows-Setups passen, kopiert aber keine geschützten Designs, Marken oder Icons.

## Farben

- Hauptfarbe: kräftiges Orange
- Akzent: Amber
- Dark Surface: Dunkelgrau
- AMOLED: Schwarz
- Light Mode: warme helle Oberflächen

## Themes

- Light Mode
- Dark Mode als Standardrichtung
- AMOLED Dark Mode
- Dynamic Color optional

Dynamic Color darf die App ergänzen, aber das orange Theme bleibt Vorrang.

## Icon

Das App-Icon ist als eigenständiger moderner Dateiordner angelegt:

- orange Farbfläche
- Dateiordner-Silhouette
- Kompass-/Explorer-Anmutung
- kein Xiaomi-, Windows-, MIUI- oder Android-Systemicon-Klon

## Navigation

Die Hauptnavigation lautet:

- Start
- Dateien
- Cloud
- Netzwerk
- Werkzeuge
- Einstellungen

## UI-Richtung

Die App soll wie ein echter Datei-Manager wirken: direkt nutzbar, dicht genug für wiederholtes Arbeiten und klar getrennt zwischen lokalen Dateien, Cloud, Netzwerk und Sicherheitsfunktionen.
