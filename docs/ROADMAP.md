# Roadmap

## Version 1

- lokaler Datei-Manager
- orange Design
- WebDAV manuell
- Nextcloud/ownCloud manuell
- verschlüsselte Speicherung
- Backup/Restore als Datei

## Version 2

- Provider-Katalog mit ca. 70 vorbereiteten Diensten
- Bluetooth/Wi-Fi Direct Transfer
- QR-Code Pairing
- Favoriten-Sync

## Version 3

- NFC Pairing
- SMB/SFTP/FTP
- Sync-Regeln
- Duplikat-Finder lokal und Cloud
- verschlüsselter Tresor

## Version 4

- Desktop-Begleittool für Windows/Linux
- Export/Import zwischen Android, Linux und Windows
- optional Selfhost-Bridge
